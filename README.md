## Cifrado César – Java

> Nombre: Cifrado César.
> Categoría: Java.
> Tipo: Proyecto personal.
> Estado: Finalizado.

Aplicación desarrollada en Java que permite cifrar mensajes mediante el algoritmo clásico de cifrado César.

El programa solicita al usuario una frase y un número de desplazamiento, y genera un mensaje cifrado sustituyendo cada letra por otra situada un determinado número de posiciones más adelante en el alfabeto.

Funcionalidades:
-Introducción de frases mediante consola.
-Selección del desplazamiento del cifrado.
-Validación de números positivos.
-Compatibilidad con letras mayúsculas y minúsculas.
-Conservación de espacios, números y signos de puntuación.

Tecnologías y conceptos utilizados:
-Java
-Scanner
-Estructuras de control
-Manipulación de cadenas y caracteres
-Operaciones aritméticas y módulo
